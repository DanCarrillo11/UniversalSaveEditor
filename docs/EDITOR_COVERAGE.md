## No-save browsing

Click a game with no available save to browse a read-only example. The banner
says **No save data found**. Example values are not a real save. Open a save
to edit; previews never write files or enter recent-file history. Available
fields depend on the file, revision and selected slot. Gameplay and system
profiles can expose different tools. `assets/editor-previews.json` is generated
from synthetic adapter fixtures, with no personal saves or writable offsets.
