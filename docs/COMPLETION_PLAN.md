# Complete existing games before adding more

New game additions are paused. The priority is useful editing, correct names,
validation for the existing catalogue. Original icon work is deferred until functionality is complete. Resident Evil,
starting with Requiem, comes first. No game is currently labelled full support.

A game is complete only against a documented feature list for its supported
edition. Every operation needs correct identities, valid ranges, dependent-field
handling and preservation of unrelated data. Offline preview visibility is not
evidence that an operation works. File checks and game-loading checks are tracked
separately. No percentage is guessed from the number of fields or icons.

The original game files or a verifiable original rip are needed where artwork
is unavailable. AI images, recolored mods, screenshots used as substitute sprites,
cross-edition images and guessed ID associations are not acceptable substitutes.
Network access denials are not worked around. Unsupported or unverified features
stay documented as pending instead of being presented as complete.
