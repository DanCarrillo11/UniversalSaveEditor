## Completion criteria

Each agreed operation needs identified data, correct bounds, dependent-state
handling, preservation of unrelated bytes, round-trip checks and in-game
verification where behavior depends on the engine. A visible preview or a
passing file checksum does not establish successful game loading or reward
delivery. Unsupported revisions and unknown encodings remain protected.

See [current coverage](EDITOR_COVERAGE.md), [implementation evidence](CURRENT_GAME_COMPLETION.md)
and [original artwork coverage](ITEM_ARTWORK.md). RE0 is research-only.
